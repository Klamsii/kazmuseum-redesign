# KAZMUSEUM — локальная версия

Сайт на GitHub Pages: https://klamsii.github.io/kazmuseum-redesign/

Редизайн [kazmuseum.kz](https://kazmuseum.kz/) с сохранением основных рубрик и реальных материалов. Интерфейс работает локально: главная страница, 23 рубрики, страницы статей, поиск и адаптивное меню.

## Запуск

```sh
npm install
npm run dev
```

Откройте адрес, который напечатает Vite (обычно `http://127.0.0.1:5173/`). Для статической сборки используйте `npm run build`; готовые файлы будут в `dist/`.

## Контент

В `public/content.json` сохранены 167 статей с главной и первых страниц рубрик, а изображения находятся в `public/assets/`. Это снимок контента, сделанный в октябре 2026 года. Полный архив исходного портала и дополнительные фотографии внутри публикаций пока не перенесены. Ссылки «Дереккөз» ведут к оригинальным статьям.

Обновить локальный снимок можно командой `npm run refresh-content`. Для неё нужен доступ к исходному сайту. При обновлении скрипт получает главную, первые восемь материалов каждой рубрики, тексты статей и основные изображения.
